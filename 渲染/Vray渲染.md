## Vray渲染器

### 快捷键速查

| 快捷键        | 功能说明                       |
| ------------- | ------------------------------ |
| **Q**         | 选择工具（选择对象）           |
| **W**         | 移动工具（平移对象）           |
| **E**         | 旋转工具                       |
| **R**         | 缩放工具                       |
| **Ctrl + A**  | 全选对象                       |
| **Alt + W**   | 最大化/还原当前视口            |
| **Z**         | 缩放视口以显示所选对象         |
| **F**         | 切换到前视图                   |
| **T**         | 切换到顶视图                   |
| **L**         | 切换到左视图                   |
| **P**         | 切换到透视图                   |
| **C**         | 切换到摄像机视图               |
| **G**         | 显示/隐藏地面平面              |
| **J**         | 显示/隐藏对象边界框            |
| **H**         | 选择对象（通过列表选择）       |
| **Ctrl + Z**  | 撤销                           |
| **Ctrl + Y**  | 重做                           |
| **Alt + Q**   | 隔离选择对象（再次按退出隔离） |
| **Shift + Q** | 渲染当前视口                   |
| **M**         | 打开材质编辑器                 |
